Open-source storage appliance

Your NAS, on the OS you choose.

FreedomNAS turns any 64-bit UNIX-like machine into a NAS: ZFS storage, SMB and NFS shares, users, network and updates, all managed from a web interface. The same code runs on Debian, FreeBSD, Arch, Gentoo, Artix and Void.

Get started Source on Codeberg
The software adapts to the system.
The system never adapts to the software.

FreedomNAS contains no native system command in its code. Every command lives in a JSON profile for the OS it belongs to, so supporting a new system means adding a profile, not rewriting the product.

Everything a NAS needs

Managed from the browser, backed by ZFS.

ZFS storage

Create pools from the web interface: stripe, mirror or RAIDZ1–3, with optional SSD cache (L2ARC) and log (SLOG) devices. Browse datasets and tune their properties.

Encrypted pools

ZFS native encryption with two independent unlock factors: a USB key for zero-touch boot, or a Master Passphrase at the console.

SMB & NFS shares

Share folders with Windows, macOS and Linux over SMB, or export them over NFS to Unix clients on your network.

Scheduled snapshots

Hourly, daily, weekly and monthly snapshots with retention you set per dataset. Only snapshots the scheduler made are ever pruned.

Safe updates

System packages, containers and firmware updated with Topgrade, live output in the browser, and an optional ZFS snapshot before every run.

Disaster recovery

Your configuration is mirrored onto every pool. Lose the OS disk, reinstall, and hostname, users, shares and policies come back on first boot.

Three interface levels

Assisted for everyday use, Advanced for full control, Expert for diagnostics. Risky actions stay hidden until you ask for them.

Secure by default

HTTPS WebUI, PAM login restricted to administrators, brute-force lockout, and passwords that never appear in logs or process lists.

How it works

The interface asks for an action, like “create a snapshot”. The engine looks up the command for the running system and executes it.

WebUI FastAPI + vanilla JS
Core Engine abstract actions
JSON profiles OS + module + init
Operating system Linux or FreeBSD

One action, every system

The same request becomes the right command wherever it runs:

engine.execute("services", "start", service_name="smbd")

systemd  →  systemctl start smbd
OpenRC   →  rc-service smbd start
runit    →  sv start smbd
bsd_rc   →  service smbd start

Built to be extended

  • Adding an OS takes JSON profiles plus a one-line entry in the engine.
  • Modules are discovered from a manifest, so community modules ship in their own repository.
  • Every command FreedomNAS can run is readable in plain JSON files.
  • Configuration stores features, not package names, so it can move between editions.

Install

Choose the path that fits your hardware.

A

Pre-built image recommended

Flash the image for your edition onto the boot disk and power on. On first boot it imports your pools, then restores an existing configuration or opens the setup wizard. The same image boots on UEFI and BIOS.

B

Installer

Boot the FreedomNAS live ISO for a clean install on a dedicated disk, or turn a machine that already runs a supported OS into a NAS in place.

sudo freedomnas-install
sudo freedomnas-install --mode inplace
sudo freedomnas-install --dry-run
C

Gentoo overlay

Install and update FreedomNAS with Portage, like the rest of your system.

eselect repository add freedomnas git \
  https://codeberg.org/FreedomNAS/freedomnas-overlay.git
emerge --ask app-nas/freedomnas

Then open https://<your-nas>:8080 in a browser to finish setup. Read the installation guide →
