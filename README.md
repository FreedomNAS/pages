# freedomnas.github.io

The FreedomNAS website, published by GitHub Pages at
<https://freedomnas.github.io/>. The documentation lives at
<https://freedomnas.github.io/freedomnas-docs/>, built from
[freedomnas-docs](https://github.com/FreedomNAS/freedomnas-docs).

The site is plain HTML and CSS: `index.html`, `style.css` and `assets/`.
Every push to `dev` publishes them through `.github/workflows/pages.yml`,
which copies those files to `_site/` and deploys them with GitHub's Pages
actions. The repository has to be called `freedomnas.github.io` for the site
to sit at the root of that address.

To look at it locally, open `index.html` in a browser.
